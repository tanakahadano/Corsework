# Реєстрація на консультацію

Одна HTML-сторінка з формою запису на консультацію до викладача. Містить розмітку (HTML), оформлення (CSS) та клієнтську логіку з перевіркою даних (JavaScript) в одному файлі, без зовнішніх бібліотек.

## Запуск

1. Збережіть `consultation.html` на комп’ютері.
2. Відкрийте файл у будь-якому браузері (подвійний клац).

Сервер, встановлення чи підключення до інтернету не потрібні.

## Можливості

- Вибір викладача зі списку:
  - Кудренко С. О. — Технології програмування
  - Кириленко А. Ю. — Апаратне забезпечення інформаційних систем
  - Пекуровський Г. В. — Технології виявлення уразливостей інформаційних систем
  - Клешня Г. М. — Філософія
- Вибір дати українською мовою: окремі списки дня, місяця (січень … грудень) та року (поточний і наступний).
- Вибір часу з півгодинним кроком: від 09:00 до 17:30.
- Введення контактних даних: ім’я та прізвище, email.
- Підтвердження запису: після успішної відправки з’являється блок із даними запису, форма очищається.

## Перевірка введених даних

| Поле | Правило |
|---|---|
| Викладач | обов’язковий вибір |
| Дата | обрані день, місяць і рік; дата існує (наприклад, не 31 лютого); не в минулому; не субота й не неділя |
| Час | обов’язковий вибір |
| Ім’я та прізвище | не менше 3 символів (пробіли по краях не враховуються) |
| Email | відповідає формату `name@domain.ext` |
| Згода | чекбокс має бути відмічений |

Поля перевіряються під час зміни та виходу з поля, а також усі разом при натисканні «Записатися». Некоректне поле підсвічується червоним із поясненням помилки.

## Структура файлу

- `<style>` — оформлення: картка по центру, адаптивна ширина, стани фокусу й помилки, автоматична темна тема (`prefers-color-scheme`).
- `<form>` — поля введення.
- `<script>`:
  - заповнення списків дня, місяця, року та часу;
  - об’єкт `rules` із правилами перевірки кожного поля;
  - функція `check()` показує або ховає повідомлення про помилку;
  - обробник `submit` перевіряє форму й формує підтвердження.

## Зміна налаштувань

- **Викладачі** — теги `<option>` у списку `#teacher`.
- **Слоти часу** — цикл у скрипті (`for (let h = 9; h <= 17; h++)`): змініть межі годин або додайте інші хвилини в `["00", "30"]`.
- **Доступні роки** — рядок із `fill($("year"), ...)`.

## Обмеження

Сторінка працює лише на стороні клієнта: дані нікуди не надсилаються й не зберігаються, а після перезавантаження сторінки запис зникає. Для реального прийому записів потрібна серверна частина.
